# Loomé - Product Landing Page

A modern and responsive product landing page built using **HTML5** and **CSS3**. The page showcases a premium cotton clothing product with a clean, minimal design inspired by modern e-commerce websites.

---

## 📌 Features

- Elegant navigation bar
- Large product showcase section
- Product description
- Available color options
- Product price display
- Add to Bag button
- Product image gallery
- Secure Payment, Free Shipping, and Easy Returns section
- Modern typography using Google Fonts
- Clean and minimal UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Google Fonts
  - Cormorant Garamond
  - Poppins
